## 🚀 Creator of iTestFlow

### [iTestFlow](https://github.com/iTestFlow/iTestFlow-Agent)

**AI-powered software testing lifecycle platform**

iTestFlow explores how AI can support software testing beyond simply generating test cases — while keeping testers in control through **project-aware context, traceability, and human review**.

### Current Capabilities

* 🔍 **Requirements Analysis** — identify ambiguity, missing information, risks, and testability concerns
* 🧪 **Test Case Design** — generate and review positive, negative, boundary, integration, and end-to-end scenarios
* 📊 **Test Gap Analysis** — analyze requirement-to-test coverage and identify missing scenarios
* ▶️ **Test Execution** — execute test steps using Playwright MCP-based agent workflows
* 🐞 **Bug Reporting** — assist with structured defect creation and Azure DevOps publishing
* 🧠 **Knowledge Hub** — build reusable project knowledge from engineering context
* 💬 **Business Owner Assistant** — answer project questions using grounded knowledge and retrieved context
* 📈 **QA Dashboards** — provide testing progress, coverage, risk, blockers, and release visibility
* 🔗 **Azure DevOps Integration** — work with requirements, Test Plans, Test Suites, test cases, bugs, and tasks
* ✅ **Human-in-the-Loop Workflows** — review and edit AI-generated outputs before publishing

### Technology Direction

`LLMs` · `RAG` · `AI Agents` · `MCP` · `Playwright` · `Azure DevOps` · `PostgreSQL` · `Next.js` · `TypeScript`

> **The goal is not to replace testers with AI — it is to make AI genuinely useful across the software testing lifecycle.**
